# Voice Agent

Offline conversational AI voice assistant built with Python.

## Features

- Real-time microphone recording
- Speech-to-text using Whisper
- Offline text-to-speech
- Silence detection
- Modular architecture

## Tech Stack

- Python
- PyAudio
- Whisper
- pyttsx3
- FFmpeg

## Pipeline

Mic → STT → Agent → TTS

## Run

```bash
python main.py
